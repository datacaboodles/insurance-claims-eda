# Insurance Claims EDA & Hypothesis Testing

Exploratory data analysis and statistical hypothesis 
testing on insurance claims data.

## Business Problem
Analyse claim patterns, detect fraud indicators, and 
understand customer demographics across segments.

## What I Did
- Merged claims and customer demographic datasets 
  into a 360-degree view
- Flagged unreported injury claims
- Removed duplicate records, retained most recent
- Imputed missing values (mean for continuous, 
  mode for categorical)
- Categorised customers by age: Children, Youth, 
  Adult, Senior
- Visualised claim trends by gender, age, fraud type
- Hypothesis testing: t-test, ANOVA, chi-square to 
  identify significant patterns

## Tools
Python · Pandas · NumPy · Matplotlib · Seaborn · SciPy
